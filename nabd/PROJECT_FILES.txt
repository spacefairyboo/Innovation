==============================================================================
  ECHO (صدى) — PROJECT FILE GUIDE
  What every file does, and whether you can live without it.
==============================================================================

  How to read this document:
  - Files are grouped the same way the folders are.
  - Under each file name you'll see one of:
      [ESSENTIAL]      the app breaks or loses a core function without it
      [NOT ESSENTIAL]  demo asset, optional feature, docs, or side project —
                       safe to remove or ignore without breaking the app
  - A short plain-English description follows.


==============================================================================
  1. ROOT — configuration and docs
==============================================================================

package.json
  [ESSENTIAL]
  Declares the app's dependencies (Next.js, React, OpenAI SDK...) and the
  npm scripts (dev / build / start). Nothing runs without it.

package-lock.json
  [ESSENTIAL]
  Locks every dependency to an exact version so installs are reproducible.

tsconfig.json
  [ESSENTIAL]
  TypeScript compiler settings. Also excludes the my-video folder so the
  video side-project doesn't break the app build.

next.config.ts
  [ESSENTIAL]
  Next.js configuration.

postcss.config.mjs
  [ESSENTIAL]
  Wires Tailwind CSS into the build. Without it no styles compile.

eslint.config.mjs
  [NOT ESSENTIAL]
  Linting rules. The app runs fine without it; code quality checks don't.

.gitignore
  [ESSENTIAL]
  Keeps secrets (.env.local), node_modules and build output out of git.

README.md
  [NOT ESSENTIAL]
  Human-readable intro to the project.

ARCHITECTURE.md
  [NOT ESSENTIAL]
  Written overview of how the codebase is organized.

AGENTS.md / CLAUDE.md
  [NOT ESSENTIAL]
  Notes for AI coding assistants working in this repo. No runtime effect.

skills-lock.json
  [NOT ESSENTIAL]
  Bookkeeping for installed assistant skills. No runtime effect.

==============================================================================
  3. src/app — PAGES (one per route)
==============================================================================

src/app/layout.tsx
  [ESSENTIAL]
  The root HTML shell: language/direction (RTL for Arabic), fonts, theme.
  Every page renders inside it.

src/app/globals.css
  [ESSENTIAL]
  All global styling: theme colors (light/dark), glass cards, chart colors,
  animations, the aurora login background.

src/app/login/page.tsx
  [ESSENTIAL]
  The sign-in page. Aurora background, frosted-glass form, bilingual.

src/app/not-found.tsx
  [NOT ESSENTIAL]
  Custom 404 page. Next.js shows a default one without it.

src/app/actions.ts
  [ESSENTIAL]
  Small top-level server actions (language/theme switching).

src/middleware.ts
  [ESSENTIAL]
  Runs before every request: blocks anyone who isn't signed in.

--- inside src/app/(app)/ — everything behind the login ---

(app)/layout.tsx

(app)/template.tsx

(app)/meeting/[id]/page.tsx  — MEETING DETAILS

(app)/notifications/page.tsx  — NOTIFICATIONS

(app)/directory/page.tsx  — DIRECTORY

(app)/profile/page.tsx  — PROFILE

(app)/tools/page.tsx  — TOOLS HUB

(app)/tools/cg-reviewer/page.tsx  — DOCUMENT REVIEWER

==============================================================================
  5. src/lib — shared logic (no server, no UI)
==============================================================================

lib/types.ts
  [ESSENTIAL]
  The heart of the domain: Task, User, Team types, status rules (effStatus
  decides "delayed" from due dates), health scoring, constants.

lib/i18n.ts
  [ESSENTIAL]
  Every English and Arabic string in the app, plus the t() translator.

lib/value.ts
  [ESSENTIAL]
  Computes a task's "value" score (drives the high-value badge).

lib/constants.ts
  [ESSENTIAL]
  App-wide constants.

lib/nlp.ts
  [NOT ESSENTIAL]
  Lightweight language parsing for the check-in assistant's local engine.

lib/parser.ts
  [NOT ESSENTIAL]
  Parses quick-entry text ("tomorrow", "high priority") into task fields.

lib/csv.ts
  [NOT ESSENTIAL]
  CSV string building for exports.


==============================================================================
  6. src/server — everything that runs on the server
==============================================================================

--- db/ ---

db/connection.ts
  [ESSENTIAL]
  Opens the SQLite database (via node:sqlite).

db/migrations.ts
  [ESSENTIAL]
  Creates/updates the tables on startup.

db/seed.ts
  [ESSENTIAL]
  Fills the database with the demo organization, users and tasks on first
  run. Without it a fresh install is an empty app with no accounts.

--- auth/ ---

auth/session.ts
  [ESSENTIAL]
  Cookie-based sessions: who is signed in, their language, sign in/out.

auth/passwords.ts
  [ESSENTIAL]
  Password hashing and verification.

--- repositories/ (all reads/writes to the database) ---

repositories/taskRepository.ts
  [ESSENTIAL]
  Everything about tasks: create, update (with the bilingual title/note
  storage the AI translation writes into), history, checklists.

repositories/orgRepository.ts
  [ESSENTIAL]
  Users, teams (units), sections, membership, scoping ("which tasks can
  this person see").

repositories/delegationRepository.ts
  [NOT ESSENTIAL]
  Delegation-of-authority records.

repositories/projectRepository.ts
  [NOT ESSENTIAL]
  Projects that group tasks.

repositories/meetingRepository.ts
  [NOT ESSENTIAL]
  Meetings shown on the calendar.

repositories/inboxRepository.ts / emailRepository.ts
  [NOT ESSENTIAL]
  Stored email suggestions and outgoing digest records.

repositories/index.ts
  [ESSENTIAL]
  Re-exports all repositories (imports across the app go through it).

--- services/ (business logic) ---

services/accessService.ts
  [ESSENTIAL]
  The permission rules: who may view, edit, or update each task.

services/translationService.ts
  [ESSENTIAL]
  The AI auto-translation: detects Arabic vs English, translates titles and
  notes to the other language (runs in the background after saves, so
  saving stays instant; mirrors text when no API key is set).

services/briefingService.ts
  [NOT ESSENTIAL]
  Builds the smart-insight line, the spoken podcast script, and the
  notification texts.

services/assistantService.ts
  [NOT ESSENTIAL]
  The check-in assistant's brain: AI-backed when configured, with a full
  local fallback engine.

services/advisorService.ts
  [NOT ESSENTIAL]
  Builds the AI advisor's plan from a task's live context.

services/docReviewService.ts
  [NOT ESSENTIAL]
  The document reviewer's analysis pipeline.

services/delegationService.ts
  [NOT ESSENTIAL]
  Delegation rules (who may delegate to whom, active windows).

services/mailerService.ts
  [NOT ESSENTIAL]
  Sends the email digest (needs SMTP configuration).

--- actions/ (the bridge the UI calls) ---

actions/taskActions.ts
  [ESSENTIAL]
  Save/create/update tasks, check-ins, and the background translation
  trigger. The busiest file in the app.

actions/authActions.ts
  [ESSENTIAL]
  Sign in / sign out.

actions/guards.ts
  [ESSENTIAL]
  Shared "is this caller allowed" checks used by every action.

actions/profileActions.ts
  [NOT ESSENTIAL]
  Saves profile preferences and delegation.

actions/assistantActions.ts / advisorActions.ts / inboxActions.ts /
actions/toolActions.ts / delegationActions.ts / systemActions.ts
  [NOT ESSENTIAL]
  One action file per optional feature (check-in chat, advisor, email
  suggestions, document reviewer, delegation, system utilities).

--- misc server files ---

server/config.ts
  [ESSENTIAL]
  Reads environment settings (OpenAI key/model, mail settings) in one place.

server/vm.ts
  [ESSENTIAL]
  Builds the "view models" pages render: task rows, org cards, activity
  feeds, top contributors, CSV rows.

server/validation.ts
  [ESSENTIAL]
  Validates and sanitizes everything the UI sends before it touches the
  database.

server/logger.ts
  [NOT ESSENTIAL]
  Small logging helper.

src/types/untyped-modules.d.ts
  [NOT ESSENTIAL]
  Type declarations for packages that ship without types.


==============================================================================

==============================================================================
  QUICK SUMMARY
==============================================================================

  If you kept only the [ESSENTIAL] files you would still have:
  login → dashboard → tasks table → task details → org overview →
  statistics, in both languages, with permissions, the database, and the
  background AI translation.

  Everything [NOT ESSENTIAL] is a layer on top: the podcast briefing, the
  AI advisor and check-in chat, calendar/meetings, notifications, the
  directory, profile/delegation, email features, the document reviewer,
  decorative visuals, and the promo-video side project.
